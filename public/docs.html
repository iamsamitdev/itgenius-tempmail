REST API

REST API สำหรับสร้างกล่องอีเมลและอ่านข้อความจากโปรแกรมอัตโนมัติ ใช้ base URL https://tm.itgenius.co.th (หรือ https://tm.itgenius.co.th/api) ตอบกลับเป็น JSON-LD (Hydra) โดยค่าเริ่มต้น ส่ง Accept: application/json เพื่อรับเป็นอาร์เรย์ JSON ธรรมดา

ขั้นตอนใช้งาน

  1. ดึงโดเมนที่ใช้ได้จาก GET /domains
  2. สร้างบัญชีด้วย POST /accounts โดยส่งอีเมลและรหัสผ่าน
  3. ขอโทเค็นจาก POST /token แล้วส่งใน header Authorization: Bearer <token>
  4. อ่านข้อความจาก GET /messages หรือรับแบบเรียลไทม์จาก GET /events
BASE=https://tm.itgenius.co.th
curl -s $BASE/domains -H 'Accept: application/json'
curl -s -X POST $BASE/accounts -H 'Content-Type: application/json' \
  -d '{"address":"demo123@tm.itgenius.co.th","password":"secret-pass"}'
TOKEN=$(curl -s -X POST $BASE/token -H 'Content-Type: application/json' \
  -d '{"address":"demo123@tm.itgenius.co.th","password":"secret-pass"}' | jq -r .token)
curl -s $BASE/messages -H "Authorization: Bearer $TOKEN"

Endpoints

MethodPathคำอธิบายAuth
GET/domainsรายการโดเมนที่รับอีเมล-
GET/domains/{id}ข้อมูลโดเมน-
POST/accountsสร้างบัญชี {"address","password"} ได้ 201 หรือ 422 เมื่อชื่อซ้ำ/ไม่ถูกต้อง-
POST/tokenเข้าสู่ระบบ ได้ {"id","token"}-
GET/meข้อมูลบัญชีปัจจุบัน (quota, used)Bearer
GET/accounts/{id}ข้อมูลบัญชีBearer
PATCH/accounts/{id}เปลี่ยนรหัสผ่าน {"currentPassword","password"} ได้ {"id","token"} ใหม่ โทเค็นเดิมทั้งหมดจะใช้ไม่ได้ ได้ 401 เมื่อรหัสเดิมผิดBearer
DELETE/accounts/{id}ลบบัญชีและข้อความทั้งหมด ได้ 204Bearer
GET/messages?page=1รายการข้อความ หน้าละ 30 รายการ เรียงใหม่สุดก่อนBearer
GET/messages/{id}ข้อความเต็ม (text, html[], attachments[])Bearer
PATCH/messages/{id}ตั้งสถานะอ่าน {"seen":true}Bearer
DELETE/messages/{id}ลบข้อความ ได้ 204Bearer
GET/messages/{id}/downloadดาวน์โหลดไฟล์ .emlBearer
GET/messages/{id}/attachment/{attachmentId}ดาวน์โหลดไฟล์แนบBearer
GET/sources/{id}ต้นฉบับ MIME ของข้อความ (data)Bearer
GET/eventsServer-Sent Events เมื่อมีข้อความใหม่ (event: message) รองรับ /.well-known/mercure?topic=/accounts/{id} ด้วยBearer

ข้อจำกัด

  • รับอีเมลอย่างเดียว ไม่รองรับการส่งออก
  • จำกัด 40 คำขอต่อ 5 วินาทีต่อ IP สร้างบัญชีได้ 20 บัญชีต่อ 10 นาทีต่อ IP เกินจะได้ 429
  • ขนาดอีเมลสูงสุด 10 MiB ต่อฉบับ พื้นที่ 40 MiB ต่อบัญชี
  • ข้อความถูกลบอัตโนมัติหลัง 7 วัน บัญชีที่ไม่ได้ใช้งาน 30 วันจะถูกลบ
  • ชื่อผู้ใช้ 3–64 ตัว ใช้ a-z 0-9 . _ - รหัสผ่าน 6–128 ตัว
